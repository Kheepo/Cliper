🚨 CRITICAL ISSUE IDENTIFIED

Root Cause: Infinite Re-render in Upload Component

Problem: The Upload component has a useEffect that depends on `isAuthenticated` and shows toast errors on every change:

React.useEffect(() => {
  if (!isAuthenticated) {
    toast.error('Authentication required', {
      description: 'Please sign in to upload videos',
      duration: 5000
    })
  }
}, [isAuthenticated])

Impact: This causes:

  • Infinite re-renders when auth state changes
  • Multiple toast notifications
  • White loading screen due to component thrashing
  • High CPU usage and memory consumption

Additional Issues Found:

  • AuthContext has complex token refresh logic with multiple retry mechanisms
  • useTokenRefresh hook can trigger frequent session refreshes
  • AuthDebug component may cause additional re-renders

React.useEffect(() => {
  // Only show error once when component mounts and user is not authenticated
  if (!isAuthenticated && !user) {
    const timeoutId = setTimeout(() => {
      toast.error('Authentication required', {
        description: 'Please sign in to upload videos',

  }
}, []) // Remove isAuthenticated dependency
